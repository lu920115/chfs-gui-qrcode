# chfs-gui-qrcode

Cute HTTP File Server 3.1 二维码增强版：单文件 Windows GUI、手机扫码共享与 GitHub Releases 更新。

## 源码与原作者署名

- Based on [docblue/chfsgui](https://github.com/docblue/chfsgui).
- 原 GUI 项目作者及版权归属详见上游项目与许可证。
- 修改版完整源码：[lu920115/chfsgui](https://github.com/lu920115/chfsgui)。
- 本仓库保留原项目的 [GNU Lesser General Public License v3.0](LICENSE)（LGPL-3.0）许可证文本。

修改版源代码和正式构建工作流均保存在上述源码仓库。源码仓库构建并提交正式 EXE 后，本仓库的同步工作流会下载、校验并提交同一份 EXE 与 SHA-256 文件，不重复编译。两个仓库的根目录各保存一份；本仓库同时用于 Releases 和程序默认更新源。工作流不会自动创建 Release。
